ROSA
An app made for women, by women.
ROSA is a full-stack wellness and lifestyle web app for women, couples, and the LGBTQ+ community. It combines cycle and mood tracking, an AI emotional-support companion, moderated community spaces, and partner sharing with privacy controls in one place.
Live: https://rosainclusive.lifestyle Status: In active development

Features
Health & wellbeing
* Period and cycle tracker with a health questionnaire (cycle regularity, contraception, stress, and other factors)
* Mood, sleep, skin, and journal tracking
* SOS / crisis-support page with resources
* Daily affirmations, quotes, letters, goals, challenges, and milestones
AI features (OpenAI)
* Floating AI support chatbot
* Food and outfit image analysis
* AI-assisted content moderation for community posts
Community & relationships
* Rose Wall (community feed) and Rose Circles (private groups)
* Friends and partner sharing with per-user privacy toggles
* A separate dashboard experience for male partners
Product
* Stripe subscriptions with webhook handling
* Founding Members program
* ROSA Garden: gamified wellness rewards
* Installable PWA (web manifest + service worker), night mode, mobile-first responsive UI

Tech stack
Layer	Technology
Frontend	React, Vite, TypeScript, Tailwind CSS, shadcn/ui
API server	Node.js, Express, TypeScript, pino logging, esbuild
Database	PostgreSQL, Drizzle ORM
API contract	OpenAPI spec, with typed client and Zod schemas generated by Orval
AI	OpenAI API (chat, vision, moderation)
Payments	Stripe
Tooling	pnpm workspaces, TypeScript project references, Prettier
Repository structure

artifacts/
  api-server/       Express API (auth, community, circles, friends, Stripe, AI routes)
  rosa-app/         React frontend (pages, components, contexts, PWA assets)
  mockup-sandbox/   UI component sandbox for design iteration
lib/
  api-spec/         openapi.yaml + Orval config (source of truth for the API)
  api-client-react/ Generated typed API client
  api-zod/          Generated Zod schemas / types
  db/               Drizzle schema and database client
  integrations-*/   OpenAI helpers (audio, image, batch)
scripts/            Utility scripts
The API is contract-first: endpoints are defined in lib/api-spec/openapi.yaml, and the client and validation schemas are generated from it so frontend and backend stay in sync.

Getting started
Prerequisites: Node.js (LTS) and pnpm 9 (corepack enable). The repo enforces pnpm.

bash
pnpm install
cp artifacts/rosa-app/.env.example artifacts/rosa-app/.env

pnpm run typecheck
pnpm run build

Environment variables

Variable	Purpose
DATABASE_URL	PostgreSQL connection string
OPENAI_API_KEY	OpenAI access
STRIPE_SECRET_KEY	Stripe server key
STRIPE_WEBHOOK_SECRET	Stripe webhook signature verification

Privacy & safety
ROSA handles sensitive personal data, so privacy is a design constraint, not an afterthought:
* Community spaces are moderated, and AI moderation runs on posts before they are shown.
* Partner sharing is opt-in and controlled by the user.
* Admin routes are separated and authenticated.
* Secrets live in environment variables only.
